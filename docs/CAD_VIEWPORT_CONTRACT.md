# CAD-T006 — isolated 3D viewport (0.6.0)

D030: reference viewport in `experiments/cad_t006/`, not the PCL studio/docking runtime. No Three.js or external rendering library. WebGL2 prototype is a portable baseline, not a final GPU backend or accelerated geometry solver.

## Run and reproduce

From the repository root, no native dependencies needed to display the bundled public native cylinder:

```sh
python -m http.server 8766 --bind 127.0.0.1
```

Open `http://127.0.0.1:8766/experiments/cad_t006/`. Use left drag to orbit, shift/middle/right drag to pan, wheel to zoom, click to select a body, F to fit, Esc to clear selection. Load another T005 JSON from the toolbar. The viewport remains separate from PCL's production panel manager; real docking integration is gated.

The sample is generated by `python -m experiments.cad_t006.fixture` with the pinned T005 build123d/OCP environment; it removes the process PID, not geometry. The source is the actual 20 × 100 mm shaft BRep tessellation (506 vertices, 500 triangles), not a browser-generated placeholder. `prepareMesh()` checks version, units, bounded arrays, finite vertices and indices, creates recentered Float32 position/normal data and Uint32 indices. This validates the transport contract, not exact BRep; selection is body-level only and triangle ID is transient, not topology naming.

## Performance contract

- Mesh replacement performs one upload of each of three retained arrays (position, normal, index); camera orbit/pan/zoom, selection and resize change only uniforms and viewport. No retessellation, native jobs or new buffer uploads on interaction. Rendering uses a single indexed draw and depth test, with RAF invalidation rather than a perpetual loop. DPR capped at 2; context restoration reuploads the retained CPU mesh once.
- Perspective camera and CPU nearest triangle ray test agree on normalized viewport coordinates; reset fits bounding sphere for current aspect, pan is in view-plane world units. GPU resources are disposed on replacement and page teardown; invalid import leaves existing mesh unchanged. File loading uses generation tokens and a 512 KiB cap.
- One body, one mesh, no assemblies, face picking, GPU compute, constraint editing, production panels or WebGPU implementation. There is no measured FPS/latency or cross-device performance claim yet.
